# เว็บไซต์งานทะเบียนราษฎร

เว็บไซต์หน้าเดียว (one-page) สำหรับประชาสัมพันธ์บริการงานทะเบียนราษฎร ประชาชนดูบริการที่มี เตรียมเอกสารก่อนมาติดต่อ อ่านประกาศ และหาช่องทางติดต่อสำนักงานได้ในหน้าเดียว

## ส่วนต่าง ๆ ของหน้า

| ส่วน | Anchor | เนื้อหา |
|---|---|---|
| Navbar | – | โลโก้ เมนูหลัก และเมนูแบบพับสำหรับมือถือ (ติดด้านบนตลอด) |
| Hero | `#home` | ข้อความต้อนรับ และปุ่มไปยังส่วนเอกสาร |
| Quick info | – | เวลาทำการ วันให้บริการ ช่องทางสอบถาม |
| บริการของเรา | `#services` | การ์ด 6 บริการ: ขอบ้านเลขที่ใหม่, แจ้งเกิด / แจ้งตาย, ย้ายที่อยู่, จดทะเบียนสมรส / หย่า, เปลี่ยนชื่อตัว / ชื่อสกุล, คัดรับรองสำเนาทะเบียนบ้าน |
| คู่มือ / เอกสาร | `#documents` | ขั้นตอนเตรียมตัว และรายการคู่มือบริการ |
| ข่าวสารและประกาศ | `#announcements` | ตารางวันเวลาทำการ และประกาศประชาสัมพันธ์ |
| ติดต่อเรา | `#contact` | ที่อยู่ โทรศัพท์ อีเมล Facebook และลิงก์แผนที่ |
| หน่วยงานที่เกี่ยวข้อง | – | ลิงก์ไปเว็บไซต์กรมการปกครอง |
| Footer | – | ข้อมูลหน่วยงาน เมนู และช่องทางติดต่อ |

## เทคโนโลยีที่ใช้

- HTML ไฟล์เดียว ไม่มีขั้นตอน build
- [Tailwind CSS](https://tailwindcss.com/) ผ่าน Play CDN
- [Font Awesome 6.5.2 Free](https://fontawesome.com/) ผ่าน cdnjs
- ฟอนต์ [Prompt](https://fonts.google.com/specimen/Prompt) จาก Google Fonts
- ภาพพื้นหลังส่วน Hero จาก Unsplash
- JavaScript สั้น ๆ สำหรับเปิด/ปิดเมนูมือถือ (`toggleMenu()`)

> ทุกอย่างโหลดจาก CDN จึงต้องต่ออินเทอร์เน็ตตอนเปิดหน้าเว็บ

## โครงสร้างไฟล์

```
.
├── index.html   # หน้าเว็บทั้งหมด (HTML + CSS + JS)
└── README.md
```

## เริ่มใช้งาน

ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์ได้เลย

หรือรันเป็น local server:

```bash
# Python
python -m http.server 8000

# หรือ Node.js
npx serve .
```

แล้วเปิด <http://localhost:8000>

## การปรับแต่ง

### สีธีม

สีหลักตั้งไว้ใน `tailwind.config` ในส่วน `<head>`:

| ชื่อ | ค่า | ใช้กับ |
|---|---|---|
| `navy` | `#102A43` | หัวข้อ, footer, กล่องเวลาทำการ |
| `primary` | `#155EEF` | ลิงก์, ปุ่ม, ไอคอน |
| `gold` | `#EAB54D` | เส้นใต้หัวข้อ |
| `lightblue` | `#EFF6FF` | พื้นหลังอ่อน |

บางสีเขียนค่า hex ตรง ๆ ไว้ใน `<style>` ด้วย (`.gold-line`, `.service-card:hover`, `.service-card:hover .service-icon`, `.announcement-item:hover`) ถ้าเปลี่ยนสีธีม ต้องแก้ตรงนั้นด้วย

### ข้อมูลติดต่อ

ที่อยู่ เบอร์โทร และอีเมล มีอยู่ **2 จุด** คือส่วน `#contact` และใน footer ต้องแก้ให้ตรงกันทั้งสองที่

### ไอคอน

ใช้ Font Awesome Free เปลี่ยนไอคอนได้ด้วยการแก้ class เช่น `fa-solid fa-baby` ค้นหาไอคอนได้ที่ <https://fontawesome.com/search> (ตั้งตัวกรองเป็น **Free**) ไอคอนที่ติดป้าย Pro จะไม่แสดงผล

### เพิ่ม / ลบบริการ

คัดลอกบล็อก `<a ... class="service-card ...">` ในส่วน `#services` แล้วแก้ไอคอน หัวข้อ และคำอธิบาย กริดจะจัดเป็น 1 / 2 / 3 คอลัมน์ตามขนาดจอให้เอง

### ภาพพื้นหลัง Hero

แก้ URL ใน `.hero-bg` ในส่วน `<style>`

## สิ่งที่ต้องทำก่อนเผยแพร่

- [ ] ใส่ชื่อสำนักงาน จังหวัด และรหัสไปรษณีย์ (ส่วนติดต่อเรา และ footer)
- [ ] ใส่เบอร์โทรจริงแทน `0XX-XXX-XXXX` (2 จุด)
- [ ] ใส่อีเมลจริงแทน `example@email.go.th` (2 จุด)
- [ ] ใส่ชื่อเพจ Facebook และทำเป็นลิงก์ (ตอนนี้เป็นข้อความเฉย ๆ)
- [ ] เปลี่ยนลิงก์ Google Maps ให้ชี้ไปที่ตั้งสำนักงานจริง หรือฝังแผนที่ด้วย `<iframe>`
- [ ] เพิ่มไฟล์คู่มือ PDF ทั้ง 4 รายการและใส่ลิงก์ (แนะนำเก็บในโฟลเดอร์ `docs/`)
- [ ] ใส่ชื่อหน่วยงานใต้โลโก้ (`<p>` ที่ยังว่างอยู่ใน navbar และ footer)
- [ ] แก้คำอธิบายการ์ด "ขอบ้านเลขที่ใหม่" ซึ่งยังมีข้อความ "ต่ออายุบัตร และกรณีบัตรสูญหายหรือชำรุด" ค้างอยู่
- [ ] ตรวจรายการคู่มือให้ตรงกับบริการบนหน้า (ยังมี "คู่มือการทำบัตรประชาชน" แต่ไม่มีการ์ดบริการนี้แล้ว)
- [ ] แก้ลิงก์หน่วยงานที่เกี่ยวข้อง: ปุ่มแรกไป `bora.dopa.go.th` (สำนักบริหารการทะเบียน) แต่ป้ายเขียนว่า "กรมการปกครอง" ส่วนปุ่มที่ 2 และ 3 ลิงก์ไปที่เดียวกัน
- [ ] สะกด "ราษฎร" ให้เหมือนกันทั้งหน้า (ตอนนี้มีทั้ง "ราษฎร" และ "ราษฎร์")
- [ ] เปลี่ยนประกาศตัวอย่างเป็นประกาศจริง และใส่วันที่
- [ ] ตรวจเวลาทำการให้ตรงกันทั้ง 2 จุด (Quick info และกล่องวันเวลาทำการ)

## ข้อควรรู้ก่อนใช้งานจริง

- **Tailwind Play CDN** ทำมาสำหรับทดลองและพัฒนา ไม่เหมาะกับเว็บจริง ถ้าจะใช้ระยะยาวควร build CSS ด้วย Tailwind CLI จะได้ไฟล์ CSS เล็กกว่าและโหลดเร็วกว่า
- **ภาพจาก Unsplash** โหลดจากเซิร์ฟเวอร์ภายนอก ถ้าจะใช้ถาวรควรดาวน์โหลดมาเก็บในโปรเจกต์
- **ข้อมูลบนหน้าเป็นข้อมูลประชาสัมพันธ์** ควรตรวจขั้นตอนและเอกสารที่ต้องใช้กับระเบียบของกรมการปกครองก่อนเผยแพร่

## การนำขึ้นเว็บ (Deploy)

เป็นเว็บ static ล้วน อัปโหลด `index.html` ขึ้นบริการโฮสต์แบบ static ได้เลย เช่น GitHub Pages, Netlify หรือ Cloudflare Pages หรือวางบนเว็บเซิร์ฟเวอร์ของหน่วยงาน
